## 🌟 Features

- ⚡ **1. Clean Energy**: Building-Integrated Photovoltaics (BIPV), Rooftop Arrays & Interactive Solar Generation Simulator.
- 🏢 **2. Smart Living**: Biophilic modular habitats & Dynamic Living Space Mode Customizer.
- 🚄 **3. Seamless Mobility**: Multi-tier transit (Sky-Rails, Autonomous Shuttles, Sub-terrene Fast Tubes) & Route Comparator.
- 💧 **4. Resource Efficiency**: Cascading Rainwater Harvesting & Stormwater Hydrological Closed-Loop Simulator.
- 🤖 **5. Automated Systems**: Subterranean AGV Logistics Corridors & Real-Time Robotic Pod Dispatcher.
- 🔍 **Interactive Blueprint & Poster Explorer**: Pulsing hotspot pins with live telemetry and engineering schematics.
- 🧮 **Citizen Impact Calculator**: Personal net-zero footprint, CO₂ savings, and energy self-sufficiency calculator.
- 🎨 **Infinity Ecosystem Architecture**: Visualizing the cloud infinity loop identity.
- 🎵 **Procedural Web Audio Engine**: Interactive synthesized acoustic feedback with mute controls.
- 🌓 **Tri-Theme Engine**: Cyber Dark, Solar Day, and Matrix Neon modes.

## 💻 Local Setup & Development
1. Clone the repository:
   ```bash
   git clone https://github.com/<YOUR_USERNAME>/promt2pixle.git
   cd promt2pixle
   ```
2. Run a local server:
   ```bash
   # Using Python:
   python -m http.server 3000
   
   # Or using Node:
   npx serve .
   ```
3. Open `http://localhost:3000` in your browser.
